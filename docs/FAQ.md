# 常见问题

> 先跑一遍「体检」：`node server.mjs --mock` 能起来、手机能打开终端里的地址，说明链路正常；本文按报错/现象分类。
> 更多细节见 [README](../README.md)、[API 映射](API-MAPPING.md)、[安全说明](../SECURITY.md)。

## 登录与额度

### 401 Unauthorized / 「密钥无效」
- 检查是否完整复制（含 `sk-` 前缀，通常 30+ 字符），前后不要带空格。
- 到 [开放平台 API Keys](https://platform.deepseek.com/api_keys) 确认该 Key 未被删除。
- 浏览器模式请确认请求真的经过本机服务（地址栏是终端打印的地址，而不是直接打开 `index.html`）。
- APK 直连时若提示网络错误而不是 401，说明是网络/权限问题，不是 Key。

### 402 Payment Required / 「余额不足」
平台扣费优先用赠送余额。到 [用量与账单](https://platform.deepseek.com/usage) 查看余额与消耗；充值后无需重启。

### 429 Too Many Requests
并发/QPS 超限。等几秒重试；批量请求请自行加队列（本应用已对 429 给出可重试提示）。

### 为什么不能像微信一样「授权登录」？
开放平台没有面向第三方应用的 OAuth，第三方无法直接使用某账号额度。本项目提供「本机预置密钥」与「粘贴密钥」两种一键路径，官方 Demo 同样只支持填 Key。

## 语音

### 点麦克风没反应 / 提示需要 HTTPS
浏览器只允许安全上下文使用麦克风。用 `node server.mjs --https`，并在手机上信任自签证书；或在本机用 `http://localhost`。

### 录音成功但识别为空
- 录音太短（<0.5s）会被丢弃；
- 环境噪声大或距离远；
- 上游 ASR 偶发 503，重试即可。

### 朗读没有声音 / 提示「朗读失败」
- 先确认右上角喇叭是否开启「自动朗读」，以及设置里的音色/语速；
- 部分 Android WebView 需要先有一次用户点击才能播放（点朗读按钮本身即满足）；
- 若播放成功却提示失败，请更新到 v1.0.1+（已修复停止时误报）。

### 为什么没有浮动播放条？
v1.0.1 起改为在回答操作栏的喇叭按钮上就地切换播放/停止，合成阶段不弹任何浮层。

## 搜索

### 「智能搜索」和独立搜索面板有什么区别？
- 对话内「智能搜索」走服务端 web 工具，**检索不单独计费**，只计 token；
- 独立搜索面板调用裸 Search API，**$0.75/千次成功请求**，界面已标价。只想省钱就用对话里的「智能搜索」。

### 引用角标点不动
角标会滚动到「参考来源」；若来源卡片没有 id 或页面被裁剪，请反馈截图与版本号。

## 文件与导出

### 上传文档失败
- 支持 PDF/Word/PPT/Excel/图片/纯文本；单文件 ≤100MB；
- 解析需要时间，上传期间不要锁屏；失败会提示具体状态码；
- Files API 是按页计费的，失败不会扣费。

### 导出的 JSON 在哪？
- 浏览器：下载目录；
- APK：`下载/DeepSeek/`（Android 10+ 走 MediaStore），旧系统在应用专属外部目录。

## 安装与升级

### 安装 APK 提示「应用未安装 / 签名冲突」
不同来源的包签名不同。卸载旧版再装，或在 CI 里配置固定签名 Secrets 后重新构建。

### 升级后设置丢了
设置存在 WebView 的 localStorage；卸载会清除。API Key 需要重新粘贴。

## 手势与显示

### 底部输入框被手势条挡住 / 顶部贴状态栏
请使用 v1.0.1+；Android 11+ 已把系统栏 insets 注入 CSS 安全区。若仍异常，请提供机型、系统版本、WebView 版本。

### 侧滑返回 / 关闭侧栏不灵
- 侧栏内左滑可关闭；底部抽屉从头部下拉关闭；搜索/设置页左缘右滑返回；
- 系统返回手势优先：会先关闭浮层，再停止生成，最后退出。

## 浏览器 / 服务器

### 手机打不开电脑的地址
- 是否同一 Wi-Fi（不要一个连 5G 一个连访客网络）；
- Windows 防火墙是否放行 Node（首次启动会弹窗）；
- 用终端打印的「手机访问」地址，而不是 127.0.0.1。

### 端口被占用
`node server.mjs --port 8788`。

### 打开页面是「Not Found」或白屏
- 确认是通过 `node server.mjs` 访问，而不是双击 `index.html`（file:// 下模块与存储都不可用）；
- APK 出现该问题说明 assets 未打进包，用 CI 产物或重新 `npm run build:android`。

### Mock 模式也 401
Mock 同样校验鉴权头；用 `?demo=1` 的演示模式，或随便填一个长度够的 Key。

## 计费与统计

### 消息底部的 ↑ ↓ 是什么？
`↑` 输入 tokens（`prompt_tokens`），`↓` 输出 tokens（`completion_tokens`）；后面依次是缓存命中率（`prompt_cache_hit_tokens`）、思考 token、首字延迟、输出速度、耗时与估算费用。

### 用量统计和账单对不上
统计只在本机、按非高峰价估算，且不含平台侧赠送/折扣差异；以开放平台账单为准。清空统计不会影响对话。

### 缓存命中率一直是 0？
短对话或首轮请求没有可复用前缀时就是 0；多轮长对话、重复系统提示词时才会明显提升。
